# Анализ рисков для разных типов данных

| Категория данных             | Возможные угрозы | Потенциальные последствия |
|------------------------------|------------------|--------------------------|
| **Персональные данные (PII)** | Утечка, кража идентичности | Финансовые потери, штрафы, репутационные риски |
| **Финансовые данные** | Перехват платежных данных, мошенничество | Крупные финансовые убытки, судебные разбирательства |
| **Коммерческая информация** | Шпионаж, утечка информации | Конкурентные потери, подрыв бизнеса |
| **Технические данные** | Взлом системы, эскалация привилегий | Компрометация инфраструктуры, сбои в работе |
| **Публичные данные** | Манипуляция, дезинформация | Минимальные риски, но возможные репутационные потери |
