# Меры защиты данных

## Персональные данные (PII)
- Шифрование при хранении (AES-256) и передаче (TLS 1.3).
- Контроль доступа по ролям (RBAC).
- Логирование и мониторинг доступа.

## Финансовые данные
- Хранение в зашифрованном виде (PCI DSS).
- Ограничение доступа только для авторизованных сервисов.
- Регулярный аудит транзакций и мониторинг аномалий.

## Коммерческая информация
- Разграничение прав на документы (DLP-системы).
- Контроль передачи информации (SIEM, журналирование).
- Защита каналов передачи (VPN, IP-ограничения).

## Технические данные
- Изоляция критически важных систем.
- Хранение API-ключей и конфигураций в защищённых хранилищах (Vault).
- Ограничение доступа по IP и двухфакторная аутентификация (2FA).

## Публичные данные
- Контроль целостности (хэширование, цифровые подписи).
- Мониторинг изменений публичных данных.
- Разграничение прав на редактирование.
