# Классификация данных и уровни чувствительности

| Категория данных             | Описание | Уровень чувствительности |
|------------------------------|----------|--------------------------|
| **Персональные данные (PII)** | ФИО, телефон, email, паспортные данные, адрес. | Высокий |
| **Финансовые данные** | Банковские реквизиты, данные платежных карт, счета. | Критический |
| **Коммерческая информация** | Договоры, отчёты, внутренние документы. | Средний |
| **Технические данные** | Логи работы системы, API-ключи, настройки инфраструктуры. | Высокий |
| **Публичные данные** | Открытые данные, новости, справочная информация. | Низкий |
